# Ujjwal Ruhal — Portfolio

A professional portfolio for Ujjwal Ruhal, an aspiring Backend Developer and Software Engineer. Built with Next.js, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Deploy

Deploy the `apps/web` directory to Vercel. No environment variables are required.
